# 小龙娘发送后情境反应设计

更新：2026-11-05，当前实现 0.1.13。用户希望开启后得到更多工作情境反馈，替代旧版“仅强烈情绪”的规则。

## 开启与告知

功能默认关闭，检测到密钥不自动开启。没有聊天窗口、多轮聊天、对话记忆或生成台词模型；Jev 只分类，客户端选择固定短句。

Jev 服务与网络页在开关旁常驻浅红色提示，不另加确认弹窗：云端调用会计费，未显示气泡的判断也可能收费；短文字发送给所选服务商，自动过滤不保证去除所有敏感信息，仍有隐私泄漏风险；频繁主动说话可能分散注意力、降低工作效率。可随时关闭，收起桌宠后完全免打扰。

关闭立即停止本功能的监听、取消在途等待、废弃候选和反应气泡。重新开启从当前 EOF 建立基线，不读取关闭期间的消息补播。已到服务端的请求可能已经产生费用，无法承诺撤回。

## 消息来源与过滤

SendingSource 通过 fs.watch 读取新增主线程提交记录，要求稳定消息身份、原始创建时间和明确的用户内容元数据。启动前历史、子代理、注入指令、工具结果和草稿都不能触发。结构化提问卡回复只使旧候选失效，不上传其包装文本。

支持纯文本与带截图的文字消息。仅处理 user.text/user.image 与实际内容块对应的结构；图片数据、图片标签、附件列表和路径不上传。Codex 的附件包装只取 `## My request:` 后的用户请求；不做 OCR，不读取附件内容。不认识的附件结构跳过。

用户文字经过 CRLF 转 LF、首尾空白去除和 NFC 归一化，原文最多 300 个 Unicode 码点；超长整体跳过，不截断。纯附件、空白、纯数值和仅含被过滤字段的消息不调用模型。

调用前在本地过滤连续至少六位数字、常见服务商密钥前缀、Bearer、JWT、凭据字段赋值、私钥块，以及较长的混合字符密钥或十六进制标识，替换成 `[已过滤]`。保留 7897 端口、401 状态码、短版本号等普通上下文。混合消息仅上传遮蔽后的短文字，日志只记类别和数量，不保存匹配值、片段或哈希。过滤是启发式，不能保证识别所有敏感内容。

## 判断与台词

一次请求包含 relation、emotion、hold_back、occasion。保留关系和情绪分类用于诊断及可信推荐路径，但用户消息分支不再要求强情绪概率达到 0.80。

hold_back 概率达到 0.50 时安静，用于用户明确要求安静、不说闲话或表示反馈妨碍紧迫操作。普通工作指令、提问、报错和催促不自动视为拒绝反馈。引用、代码、测试字符串中的意图和情绪不能冒充用户本人的表达。

occasion 为最具体的情境，所选类别概率至少 0.55 时选取固定台词：

| 场景 | 反馈原则 |
| --- | --- |
| 整体收工、程序跑通、难题解决 | 分别庆祝，不能把小步完成或采纳方案说成收工 |
| 写代码休息、修改工作休息、普通休息 | 只在用户明确打算暂停时使用对应陪伴句 |
| 返工、问题反馈 | 接住当前未达标或异常情境，不评价用户能力 |
| 认可方案 | 回应拍板，不冒充预测成功或推荐采纳 |
| 仍在工作中的烦躁、挫折 | 简短护短，不擅自劝收工休息 |
| 一般任务安排、讨论提问 | 简短陪伴、接话，不追问 |
| 无明确情境、纯引用或测试 | 安静 |

台词在 `assets/dialogue-library.json`。原用户九句保留，新增工作短句；默认每个场景至少两句轮换，个人分组只剩一句时允许在冷却后重复，避免旧版只有一句时防重复使整个场景持续沉默。称呼“老大”，偶尔自称“本龙”，机灵、有分寸、护短温柔，不使用幼态叠词、卖惨讨好或客服套话。

对话库与称呼使用方式见 [对话库编辑说明](DIALOGUE-LIBRARY.md)。个人库在更新时保留，所有展示中的 `{title}` 在本地代入自定义称呼，不上传模型。

## 推荐配对限制

Codex 自动草稿当前没有接通可信的完整文本来源。实际链路只依赖当前已发送用户文字，不声称识别草稿采纳。RecommendationSnapshots 保留已展示快照契约：同一聊天/输入轮次、完整快照、显示序号先于提交序号；无有效快照走 user_only。每条推荐最多 300 码点、总计最多 900；超限整体不提供推荐。

若当前文字或任一推荐命中敏感过滤，不走配对分支，避免上传敏感推荐，也避免不同密钥被遮蔽成同一占位符后误判相同。可信快照且无敏感内容时，才按 adopted、exact/语义等价及非强烈情绪条件选择得意台词。

## 及时性、费用与优先级

- 从消息发送时间到首次展示最多 5 秒，包含发现、网络、判断和界面获取结果。请求等待为剩余时限减去 250 毫秒，给呈现留时间；过期丢弃。
- 两次实际展示至少间隔 10 秒。冷却、隐藏、菜单/对话框占用、关闭气泡、重要业务提醒时，在模型调用前跳过，避免明知不能显示仍产生费用。
- 每个消息最多分析一次，每分钟最多 30 次调用，同时只保留最新候选。新消息、隐藏、关闭、模式切换和业务阻止取消旧候选，恢复后不补播。
- 一次一条气泡，实际展示后至少停留 8 秒，长文字按码点数量延长、最多 15 秒；点击可提前收起，无追问、不抢焦点、不排队。真实提问、授权、额度和完成气泡优先。收起及动画期间所有气泡、音效和提醒点停用。
- 认证错误停止本次开启周期的自动请求；临时网络或服务错误退避 30 秒，之后仅由新消息触发，不自动重试。

## 服务配置

支持 OpenRouter、TypeSafe 官方和兼容 Decisions / System One 的自定义端点、模型及密钥环境变量。`jev-settings.json` 只存环境变量名，不存密钥；新增用户环境变量后需重启进程。

网络可选直连或指定无认证 HTTP(S) 代理。直连忽略代理环境变量；指定代理忽略 NO_PROXY 绕过，失败不降级直连，不自动跟随重定向。测试只发固定合成句，不自动保存或启用。本机外部实测经 7897，其他用户可配置自己的端口或直连。

## 内部触发日志

私有数据目录 `jev-reactions.jsonl` 满 1 MiB 轮换为 `jev-reactions.previous.jsonl`，最多两个文件。不新增用户界面、导出入口或自动上传。

每次运行有运行标识，每条新消息有随机追踪号，不使用原始聊天或消息 ID。记录监听就绪、文字长度、过滤数量、跳过原因、请求开始与耗时、经过校验的分类及概率、候选就绪、取消、过期、renderer 拒绝和实际展示确认。请求失败只写固定错误类别，不写服务响应或异常正文。

日志不包含正文、推荐、图片数据、密钥、端点、附件和源文件路径。Git 和发布包均排除日志。磁盘满或权限错误会停用本次运行的日志，并在控制台报告固定错误类别，不让日志失败打断反馈。

同一次 Jev 请求还标注 `mood`（平常、满意、不满、疲惫、担忧、难过、不确定）和 `intent`（认同、商量、反对、请教、继续、安排、反馈、不确定）。这两个标签只用于本地统计，不改变气泡选择规则，不增加第二次请求；具体费用仍按服务商计价。记录各自选项及概率，低于 55% 单独计为低置信度，不能把模型标签当作真实心理状态。

私有目录 `jev-statistics.json` 按本机日期累计有效判断总数、两类标签的次数和低置信度次数，不保存原话、追踪号或聊天标识。日志轮转、重启均不清空累计；文件损坏时保留原文件、暂停累计，决策日志继续记录。每次成功返回并通过校验的判断计一次，即使明确安静、低置信度、结果过期或界面取消导致没有气泡，也保留统计；中止请求未取得结果、失败及调用前跳过不计数。不追加云端请求补齐缺失数据，不回溯分析历史消息。统计因此仅代表 Jev 实际分析的样本，并非全部发言。关闭功能后不新增分类，已有本地计数保留。该文件由 Git 和发布打包规则排除。

## 验证与已知限制

相关回归覆盖来源去重/历史/截图文字、过滤与不上传边界、工作场景、轮换、冷却前不调用、5 秒窗口、日志轮换与无正文、隐藏和取消。隔离 Electron 验证真实监听、HTTP、协议、气泡及展示确认；真实 Jev 仅使用合成样例。结果见 [验证记录](VALIDATION.md) 与 [测试计划](INTENT-AWARENESS-TESTS.md)。

没有可靠的 Codex 内部聊天切换事件；仅切换聊天但不发送、隐藏或切模式时，不能保证立即使候选失效。会话时间戳不能证明真实点击到落盘延迟。小样本测试不代表长期触发率或过滤完整率，也不能将假服务和合成输入称为原生用户验收。
