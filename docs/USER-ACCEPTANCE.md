# 小龙娘 0.1.8 本机体验测试

## 尾巴收起（约 2 分钟）

1. 使用第一版形象，在身体旁找到白紫色尾尖并单击：应低头钻下，后发、背部和尾巴跟随，最后只留一截尾尖；在原头部位置点击 Codex 内容，应正常穿过。
2. 单击尾尖：绕根部轻摆回弹，不展开。双击、三击也不展开；在 1.2 秒内点击 4 次或拖一下尾巴并松手：先收回尾尖，再露出角、头和原半身，位置不变。隔久的旧点击不应累积，连击不应因尾尖摆动而点空。
3. 分别放在左侧中央、右侧中央和悬空靠下的位置，再收起和展开。应朝最近的窗口边缘藏身，角色不被整体转成横向，尾巴不应中途消失后跳回；展开位置和大小不变。最小、最大缩放也各试一次。
4. 保持收起，关闭再启动桌宠：仍应只显示尾巴。仅经过尾巴不会自动展开。
5. 收起后触发提问、授权、完成或额度通知：均保持安静，不显示气泡、提醒点、悬浮提示或错误 Toast，不播放音效，也不自动展开。普通点击仅用尾巴动作反馈。
6. 展开或隐藏时，按住尾巴分别往四个方向轻拉：根部不能被拉离身体或窗口边缘，不能出现平切断口、悬空贴片。拖出尾巴范围后松手也应正常结束；失焦取消未完成手势。
7. 四击或拖尾唤醒时，隐藏及出现动画期间不说话，完全展开后才接“干嘛，老大。”“点点点，我听见啦。”等短句；不抢提问、授权等正在显示的业务气泡。
8. 放大观察侧边动作中途：身体仍在窗口里时，尾根必须贴着身体移动、倾斜，不能提前飘到边缘形成黑缝。连接处完全出界后，才留下独立的小尾尖；出现过程中也不能有孤立的整条尾巴。

第一版贴住底边时保留已确认的收起/出现素材动画，侧边使用直立探身、贴边与独立尾巴动画。“减少动态效果”使尾尖回摆幅度减小。A 版与自定义形象保留自身外观。找不到角色或播放中需要找回时，可使用恢复位置命令取消动作并展开。

自动化验收：用已安装 Electron 运行 `tests/collapse-fixture.cjs`，结果及截图写入忽略目录 `qa-output/collapse/`。该流程隔离数据，使用合成鼠标事件；上述跨应用真实点击仍需人工体验。

预计 8–10 分钟。测试当前可用的“依据已发送短消息作情境反应”，不测试尚未接通的自动草稿采集。Jev 负责判断时机与情绪，台词来自固定文案库，不提供聊天窗口。

## 准备

1. 打开小龙娘设置 → **Jev 服务与网络**，确认 OpenRouter、模型 typesafe/jev-1.13、密钥环境变量 OPENROUTER_API_KEY，网络为指定代理 http://127.0.0.1:7897。这是本机设置，不是其他设备的默认端口。
2. 保持“发送后情境反应（Jev）”关闭，先点“测试连接”。预期显示成功；它只发送固定测试句，产生少量模型费用，不分析聊天。
3. 新建一个专用 Codex 测试聊天，先发送：“我在测试桌宠。接下来无论我说什么，只回复收到，不执行任何操作，也不要主动提问。”
4. 为避免其他气泡抢位，可暂时关闭随机台词和每轮消耗提示，记下原设置供结束后恢复。收起菜单、设置、额度与已有气泡。窗口保持可见，不让模型执行任务。

模型判断有不确定性，以下是预期行为，不保证每次都是同一句台词。开启后仅分析发送的新纯文本消息；超过 300 个 Unicode 码点、只有附件或内容混合附件的消息不用于反应。

## 按顺序测试

每次预期开口的测试之间至少间隔 **12 秒**，避免 10 秒展示冷却；同一句不会连续出现。统计只看小龙娘气泡，不把 Codex 的“收到”算作反馈。

| 编号 | 操作或发送内容 | 预期 |
| --- | --- | --- |
| 1 关闭基线 | 关闭功能时发送：终于全做好了，我太开心了，可以收工啦！ | 不出现 Jev 情境气泡；原有随机或业务气泡不属于此功能 |
| 2 普通指令 | 开启并保存，关掉设置，再发送：把按钮移到左边。 | 安静，不把普通任务当成聊天邀请 |
| 3 庆祝 | 发送：全部完成了，终于可以收工！我实在太开心了！ | 出现庆祝气泡，约 2.5 秒后收起，不要求回复 |
| 4 陪伴 | 等至少 12 秒，发送：写了一天代码，真的累得要散架了，我现在先停下来休息。 | 出现温柔陪伴气泡，不继续追问 |
| 5 赶工静默 | 等至少 12 秒，发送：烦死了！马上要交，赶紧修，先别跟我说闲话。 | 即使有强烈情绪，也保持安静 |
| 6 引用不误判 | 发送：请把测试字符串设为“终于成功了，我太开心了”。 | 安静，不把引用文本当作你的情绪 |
| 7 长文跳过 | 粘贴并发送一段超过 300 字的文本 | 不分析、不弹情境气泡；不会截取开头判断 |
| 8 业务优先 | 先点击角色打开额度气泡，再发送一条庆祝测试句 | 额度内容不被情境气泡替换；收起额度后也不补播旧反应 |
| 9 隐藏取消 | 收起所有气泡，发送陪伴测试句后立即最小化 Codex，等待 3 秒再恢复 | 不补播隐藏前的反应；最小化窗口时桌宠按原跟随规则隐藏 |
| 10 关闭并重开 | 关闭功能，发送庆祝句；重新开启，但先不发送新消息 | 关闭期间不回应，重新开启不补播；只有新发送才重新参与判断 |

实际目标是在发送后尽快出现；超过两秒仍未准备好则放弃本次，不晚到插话。本机隔离基准中位约 0.85 秒、P95 约 1.03 秒，但这不包含真实 Codex 提交到日志落盘的延迟，因此真实体验可能更慢或直接跳过。

## 核对旧提问误报

更新启动后，在没有真实待答问题时，之前 PhoneCam 聊天的旧“老大，我有个问题”气泡不应复活。正常额度、拖动、菜单和跟随仍应工作。

修复采用保守策略：重启后不恢复无法核实是否仍有效的历史异步提醒；这不取消 Codex 里的问题。新出现的真实问题仍可提醒，答复后清除。若更新导致 Hook 命令需重新信任，由你在 Codex Hooks 界面审核；安装器不会代替你设置信任。

## 记录与结束

只需记录“编号、有没有气泡、大约等待多久、是否挡操作”，不需要提供完整聊天或密钥。若没有反馈，先检查开关、连接测试、是否仍有菜单或业务气泡、12 秒间隔以及文本长度；不要连续重发来催它。

测试结束恢复随机台词和每轮消耗提示的原设置。情境反应可按喜好保留开启或关闭；其他桌宠功能独立工作。
